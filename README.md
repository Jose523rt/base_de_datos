# base_de_datos
Repositorio que contiene el progreso del desarrollo de la base de datos del equipo Kduco

## Reporte de progreso

### 17 de octubre
Se realizó el bosquejo de nuestra base de datos, con el objetivo de plasmar los elementos esenciales para la correcta funcionalidad del sistema de nuestra base de datos 

### 22 de octubre 
Se realizó la primera versión de nuestro modelo relacional (MER) con la ayuda del software DB Designer, al igual que nuestro modelo entidad-relación en draw.io.

### 30 de octubre
Se empezaron a realizar cambios en los modelos de la base de datos (MER y entidad-relación) corrigiendo incongruencias y agregando elementos, dando a lugar a nuestra siguiente versión 

### 6 de noviembre 
Se hicieron ajustes en los modelos (MER y entidad-relación) con el fin de hacer muchisimo más entendibles todas las funcionalidades en nuestra base de datos, dejando unicamente elementos esenciales y puntuales.

### 11 de noviembre
Se ajustaron elementos esenciales en la base de datos dando a lugar otra de nuestra versiones, siendo esta una base de datos con nuevos elementos importantes

### 19 de noviembre
Se realizaron cambios en nuestros modelos (MER y entidad-relación) dando a lugar a nuestra versión más actual de nuestra base de datos, realizando las correcciones necesario en cuanto a nuestros tipos de datos, primary keys y foreing keys. 

### 4 de diciembre
Se eliminaron el campo producto_id y sus respectivas llaves foráneas de las tablas categoria_productos, producto_marca y caducidad.
Este cambio se realizó para evitar redundancia, simplificar las relaciones y mantener un modelo más limpio y correctamente normalizado.
